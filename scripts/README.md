# تعليمات فكّ التشفير (README)

هذه الملفات أضيفت لمساعدتك على استخراج سلاسل Base64 من ملف ثنائي (blob) ومحاولة فكّها باستخدام مفتاح بصيغة hex أو base64.

الملفات المضافة:
- scripts/extract_strings.py  — يستخرج سلاسل محتملة بصيغة Base64 من الملف.
- scripts/try_decrypt.py     — يجرب فكّ سلسلة Base64 باستخدام مفتاح (AES-GCM ثم AES-CBC).

تحذيرات أمنية:
- لا ترفع المفاتيح أو التوكنات الحسّاسة إلى مكان عام. شغّل هذه السكربتات محلياً على جهازك.
- السكربت لا يحاول أي تشفير متقدم؛ يجرب فقط نمطي AES-GCM وAES-CBC بالشكل الشائع.

المتطلبات:
- Python 3
- PyCryptodome: تثبيت عبر:

  pip3 install pycryptodome

كيفية الاستخدام:
1) انسخ الملف الثنائي إلى جهازك، مثلاً باسم blob.bin
2) استخرج المرشّحات (سلاسل Base64 المحتملة):

   python3 scripts/extract_strings.py blob.bin

   سيطبع السكربت قائمة بالسلاسل المحتملة مع أرقام.

3) اختَر سلسلة (أو انسخها) ثم جرّب فكّها بالمفتاح لديك (المفتاح إما بصيغة hex أو base64):

   python3 scripts/try_decrypt.py "BASE64STRING" "KEY_HEX_OR_BASE64"

4) سيحاول السكربت فكّها كـ AES-GCM أولاً (يفترض IV=12 بايت وTAG=16 بايت)، ثم AES-CBC (يفترض IV=16 بايت وPKCS#7 padding).

ملاحظات متقدّمة:
- إذا كان التشفير يضيف ضغطاً أو صيغة مخصّصة، قد تحتاج أدوات/معلومات إضافية (مثل طريقة ترتيب IV/CT/TAG أو مفتاح مشتق عبر PBKDF2).
- إن رغبت، بعد تشغيل الأدوات محلياً، انسخ هنا النتيجة الآمنة (مثل النص المفكوك بدون مفاتيح) وسأساعدك تفسيرها.
